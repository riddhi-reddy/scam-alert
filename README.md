# Scam Alert interactive prototype

## Open in Visual Studio Code
1. Extract the ZIP first.
2. In VS Code, choose File > Open Folder and select scam-alert-vscode.
3. Open index.html, styles.css or app.js to edit the interface.

## Run
Double-click index.html in File Explorer to open it in your browser. No installation, API key, backend or build command is required.

Alternatively, if the VS Code Live Server extension is already installed, right-click index.html and choose Open with Live Server.

## Files
- index.html: page structure
- styles.css: colours, spacing, responsive layout
- app.js: screens, scenario data and interactions
- .nojekyll: static GitHub Pages publishing

## Scope
This is an academic interactive prototype. All calls, reports and feedback are simulated. Message analysis uses illustrative local rules, not a trained AI model. No entered messages are sent to an external service. Session settings reset on reload. Language selection saves a preference only; the interface remains in English.
